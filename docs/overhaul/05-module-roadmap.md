# Module Roadmap

Enhanced functionality and forward planning. Ship in phases; this doc is the backlog of *intent*.

## Overview (new)

- Project stats and progress.  
- Recent work and activity feed.  
- Quick links into other sections.  
- Optional pinned entities / continue writing CTA.

## Manuscripts (keep + deepen)

**References:** Scrivener, Lore Forge scenes, Campfire manuscript.

| Capability | Priority | Notes |
|------------|----------|-------|
| List + rich editor | Existing | Keep Quill + grammar integration |
| Nested structure (binder mindset) | High | Chapters/sections as hierarchy, not one blob |
| Corkboard / card overview | Medium | Scene/chapter cards, reorder |
| Outliner view | Medium | Same data, dense structure view |
| Side reference / pin entity | High | Link Character/Location while writing |
| Distraction-free mode | Medium | Hide chrome |
| Collections / filters | Later | Scrivener-like groupings |
| Diff / history | Existing | Preserve and surface cleanly |

## Characters (keep + deepen)

**References:** Lore Forge, Campfire, LegendKeeper elements.

| Capability | Priority | Notes |
|------------|----------|-------|
| Card grid + detail inspector | High | Match simplified Figma pattern |
| Traits, bio, relationships | Existing | Cleaner layout, optional sections |
| Concept art / assets | Medium | Attach images without heavy forms |
| Status / completion dots | Low–Med | Lore Forge-style progress |
| Role filters & search | High | |
| Link to manuscripts / scenes | High | appears-in style links |
| Relationship viz entry | Medium | Jump to Lore Map or mini-graph |

## World Building (consolidated)

### Magic

- Systems with rules, source, practitioners (prototype-like cards).  
- Link practitioners → Characters.  
- Avoid empty mandatory forms; optional sections.

### Timelines

**References:** Aeon Timeline, LegendKeeper timelines, World Anvil Chronicles.

| Capability | Priority | Notes |
|------------|----------|-------|
| Event list + canvas | High | Zoom, lanes/groups |
| Inspector on event | High | |
| Link event → characters, locations, factions | High | Chronicles-style binding |
| Custom calendar integration | Medium | Use Calendar systems |
| Map-aware events (Chronicles) | Later | Event focuses map / changes map state |

### Calendars

- Custom month/day structures (existing domain).  
- Tie timeline events to calendar dates.  
- Simple month view for planning.

### Species / Locations / Cultures / etc.

- Entity pages with flexible sections (not 20 required fields).  
- Tags, images, backlinks.  
- Locations link to Map pins when Map is available.

### Maps

**References:** Inkarnate, LegendKeeper map tool.

| Capability | Priority | Notes |
|------------|----------|-------|
| Image map + pins | Existing / improve | Link pin → Location / Character |
| Regions / paths | Later | |
| Nested maps | Later | World → region → site |
| Embed in Overview or Location | Later | |

### Arcs / Plot

**References:** Plottr.

- Plotlines + scene cards.  
- Filter by character/place/tag.  
- Can live under World Building or as a Manuscript companion view.

### Relationships

- List + visual graph (feeds Lore Map).  
- Types: ally, rival, family, etc.

## Lore Map (connectivity)

**References:** Obsidian graph (philosophy), LegendKeeper links.

- Nodes: characters, manuscripts, locations, magic, species, …  
- Edges: appears-in, relationship, practices, located-in, origin, …  
- Filters by type; click → open entity.  
- Not the default home screen; a dedicated lens on the web of lore.
